configuiとは

ローカル専用のブラウザ設定UI。persona.jsonを安全に編集するために追加した。

cd C:\\dev\\mixi2-plugins\\base-bot\ngo run ./cmd/configui

ブラウザで http://127.0.0.1:8787 を開く。

ボタンの意味

ボタン動作
保存ローカルのpersona.jsonを保存。バックアップ作成。
保存してRailway反映persona.jsonを保存し、git commit / push。Railwayが再デプロイ。
バックアップのみ現在のpersona.jsonをバックアップ。

このサイトは作業共有用。APIキー、Client Secret、Railway Variables、.env、ログ、個人データは掲載しない。
