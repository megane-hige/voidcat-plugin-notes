全体の流れ

公式配布や空のBaseテンプレートを受け取っただけでは、そのまま自分のBOTとして運用できません。自分のmixi2 Pluginアプリ、自分のOpenAI APIキー、自分のGitHub repo、自分のRailway環境、自分の人格と素材を用意します。

手順

  1. テンプレートをローカルへ置き、go test ./... を通す。
  2. 自分のGitHub Private repoを作る。
  3. mixi2 Developer PlatformでPluginアプリを作る。
  4. Requirementを設定し、Application Versionを更新する。
  5. 対象コミュニティへPluginをインストールまたは再許可する。
  6. persona.jsonとassetsを自分のBOT用に差し替える。
  7. OpenAIとmixi2の確認コマンドを通す。
  8. Railwayへデプロイし、VariablesとVolumeを設定する。
  9. Deploy successfulとログを確認する。
