このサイトについて

このサイトは、mixi2コミュニティ用Plugin「虚無猫」を作っていった作業記録を、あとから読める記事として整理したもの。

ただのコマンド集ではなく、フォルダ構成、機能の役割、GPTとの対話で決めたこと、実際につまずいた点を入れている。読んでいくと、mixi2 Plugin型BOTがどんな部品でできているのか、なんとなく見える構成にした。

既存Plugin動くものをコピー
base-bot人格と機能を分離
虚無猫人格設定を追加
Railway本番稼働
GitHub Pages作業ログ公開
