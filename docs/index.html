完了した作業

1. Railway本番稼働確認

Railway上でPluginのデプロイ成功を確認。サービスがオンラインで、Volumeがマウントされ、 cmd/streamcheck が起動してgRPCストリーム待機状態になっていることを確認した。

missing env、PermissionDenied、panic、restart loop は見当たらず、本番稼働状態として問題なし。

2. 虚無猫 persona の文字化け修復

personas/kyomu_neko/persona.json が文字化けしていたため、UTF-8として正常に読み込める状態へ修復した。 PowerShellに日本語を直接流すと文字化けしやすいことも確認済み。

3. 反応ワード調整

コミュニティ内の呼称と衝突しないように、汎用的すぎる「猫」「猫さん」「ねこさん」を除外。 現在の反応ワードは以下。

虚無猫さん 虚無猫 虚無さん パイセン

4. configui 追加と日本語化

ローカル専用の設定UI cmd/configui を追加。ブラウザで人格設定を編集できるようにした。 

cd C:\dev\mixi2-plugins\base-bot
go run ./cmd/configui

ブラウザで以下を開く。

http://127.0.0.1:8787

5. 「保存してRailway反映」ボタン追加

configuiに「保存してRailway反映」ボタンを追加。人格設定だけなら、UIから保存してGitHubへpushし、 Railwayの再デプロイまで流せる形になった。

FEATURESやスケジュールの変更はRailway Variables側の手動変更が必要。自動反映対象は基本的に persona.json。
