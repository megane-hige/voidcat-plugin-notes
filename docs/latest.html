三体標準化、Config UI最終調整、Railway確認、記事サイト再構成の作業記録

最終更新: 2026-06-16 mixi2 Plugin GitHub Pages

今回の更新概要

今回の作業では、虚無猫、シベリア・フジタ、空想アイの3体Pluginを同じ考え方で扱えるように標準化した。以前は虚無猫だけ base-bot 名義のまま扱っていたため、フォルダ名と役割が混線しやすかった。これを整理し、虚無猫も他2体と同じ専用repo構成に揃えた。

今日行った主な作業

虚無猫を専用repo化

base-bot を mixi2-community-voidcat-plugin へ移し、虚無猫専用Pluginとして整理した。不要な personas/base、personas/fujita、personas/nanchatte_ai、不要なassetsを削除し、kyomu_neko だけを残した。

base-botを共通テンプレに再定義

base-bot は本番用repoではなく、今後のコピー元・共通テンプレとして扱うことにした。Railway本番には直接使わない。

Config UI最終調整

人格選択、人格シート、機能ON/OFF、ローカル.env補助設定、Railway Variables確認欄を整理した。設定UIは本番Railwayを直接変更するものではなく、ローカル設定とpersona.jsonの編集補助として位置づけた。

一発起動batとショートカット作成

open-configui.bat を作成し、虚無猫、フジタ、空想アイ、base-botを番号選択で起動できるようにした。文字化けを避けるため、batはASCIIで作成し、ブラウザ自動起動も安定化した。

GitHub同期確認

3体の専用repoが main...origin/main で揃っていることを確認した。虚無猫は構造整理commitをpush済み。

Railway確認

VoidcatのSecrets空欄問題、フジタのVolume表示なし問題を確認した。Railway側では、Secretsの実値復旧と、必要なVolumeのマウント確認が残作業になる。

マニュアルと記事サイトの再構成

旧マニュアルと旧詳細記事を、現在の構成に合わせて再構成した。ページ数を整理し、スマホでも横に広がりにくい構造へ調整した。

現在の残確認

  • Railwayの各サービスで最新Deployが成功していること。
  • フジタに /data Volume が付いていること。
  • Voidcatの MIXI2_CLIENT_SECRET と OPENAI_API_KEY が空ではないこと。
  • Variablesを貼り直す時に、空欄のSecretで上書きしないこと。
