Railway本番稼働

RailwayではPlugin本体として cmd/streamcheck を起動。configuiはローカル専用であり、Railway上では起動しない。

確認済み：サービスオンライン、Volumeマウント、gRPCストリーム待機、missing envなし、PermissionDeniedなし、panicなし。

Dockerfile Volume対応

RUN mkdir -p /app/logs /app/data /data/logs /data/state

CMD ["sh", "-c", "mkdir -p /data/logs /data/state /app/logs /app/data && /app/base-bot"]

Railway Volume mount path は /data。ログや状態ファイルは /data 配下へ逃がす。
