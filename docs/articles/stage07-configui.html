第39.5〜39.6段階 / 人格編集UI

文字化け事故から、ブラウザ編集UIへ

虚無猫のpersona.jsonをPowerShellで確認したら、日本語が完全に文字化けしていた。そこで復旧しつつ、今後はJSONを直接手で編集しない方針に切り替えた。

configuiの役割

cmd/configui はローカル専用の設定UI。ブラウザでpersona.jsonを編集できる。

go run ./cmd/configui
http://127.0.0.1:8787

保存してRailway反映

人格設定だけなら、UIから保存してGitHubへpushし、Railway再デプロイまで流せるようにした。

ただし、FEATURESやスケジュールはRailway Variables側の手動変更が必要。ここは今後UIにも明記する。

現在の虚無猫

反応ワードは「虚無猫さん」「虚無猫」「虚無さん」「パイセン」。コミュニティ内の実在呼称と衝突する「猫」「猫さん」「ねこさん」は除外した。
