第39.5〜39.6段階 / 人格編集UI

文字化け事故からconfiguiへ

虚無猫のpersona.jsonをPowerShellで表示したら、日本語が完全に文字化けしていた。これで、JSONを直接編集する運用は危ないと分かった。

作業者めっちゃ化けてるｗ
GPT表示だけでなくファイル自体が壊れているので、人格JSONを作り直しましょう。今後はUIで編集する方が安全です。

configui

cmd/configui はローカル専用のブラウザUI。人格設定をフォームで編集できる。

go run ./cmd/configui\nhttp://127.0.0.1:8787
configuiの画面。反応ワード、口調、禁止事項、システムプロンプトをブラウザで編集できる。

保存してRailway反映

人格設定だけなら、UIから保存してGitHubへpushし、Railway再デプロイまで流せるようにした。

FEATURESやスケジュールはRailway Variables側の手動変更が必要。自動反映対象は基本的にpersona.jsonのみ。
