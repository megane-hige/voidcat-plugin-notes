第01回：動いているPluginをbase-botへ分岐する

既に動作していたシベリア・フジタPluginを直接壊さないため、まずは別フォルダへ丸コピーした。最初に目指したのは新機能ではなく、同じ状態でビルドできる安全な作業場を作ることだった。

この段階では、まだ人格や素材をきれいに分けない。先に全体の依存関係、Go module、cmd配下の入口、internal配下の処理がそのまま動くかを確認した。

確認は必ずコピー先で行い、go build ./...を通した。ここで通らない場合は、汎用化以前の問題としてコピーや依存関係を直す必要がある。

作業上の重要点は、フォルダ名とrepo名を混同しないことだった。後に虚無猫でこの混同が問題になったため、この段階の考え方は現在の三体標準化にもつながっている。
