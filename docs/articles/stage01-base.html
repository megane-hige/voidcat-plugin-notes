第01〜08段階 / 土台づくり

まずは「動いているPlugin」を壊さずコピーする

今回の作業は、ゼロからBOTを書くところから始めていない。すでに動いているシベリア・フジタPluginがあり、それをベースにして「他の人格にも使い回せるbase-bot」を作るところから始めた。

最初から完璧な設計を狙うより、動くものを丸ごとコピーして、そこから少しずつ名前を外し、人格を外し、機能を切り出していく。GPTとの対話でも、この方針を先に決めた。

作業者これ、フジタ用じゃなくてベースBOTにできない？
GPTまずコピーして、ビルドが通る状態を保ったまま人格・素材・機能を切り出しましょう。

作業フォルダ

C:\dev\mixi2-plugins\ ├─ base-bot\ 今回の作業本体 ├─ base-bot_stable_...\ 途中の安定版バックアップ └─ base-bot_voidcat_...\ 完成版バックアップ

base-botの基本構成

base-bot/ ├─ cmd/ 起動コマンド。streamcheck、configcheck、configuiなど ├─ internal/ Plugin本体のGoコード。handler、scheduler、configなど ├─ personas/ 人格設定。kyomu_neko、fujita、baseなど ├─ assets/ 画像素材・参照画像フォルダ ├─ scripts/ PowerShell補助スクリプト ├─ docs/ 作業メモ、仕様、GitHub Pages用ファイル ├─ Dockerfile Railwayで動かすためのコンテナ定義 ├─ railway.toml Railway設定 └─ go.mod Go module定義

この構成を見れば、BOT制作の大枠が分かる。cmd は入口、internal は中身、personas はキャラ、assets は素材、scripts は作業補助。
