第01〜08段階 / 既存Pluginからbase-botへ

動くものをコピーして、壊さずに汎用化する

最初にやったのは、シベリア・フジタPluginをそのまま base-bot にコピーすることだった。新規開発ではなく、すでにmixi2と会話できるPluginを元にする。ここで重要なのは、最初から理想の構成へ書き換えないこと。動いている部分を残し、人格や素材だけを少しずつ外に出していく。

作業者これ、フジタ専用じゃなくて他のコミュニティ用にも使えるベースにしたい
GPTまずコピーしてビルドが通る状態を固定しましょう。次に人格、画像素材、機能フラグを順に切り出すのが安全です。

この判断で、作業はかなり安定した。もし最初にhandlerを全面改造していたら、mixi2認証なのか、OpenAI接続なのか、人格設定なのか、どこで壊れたか分からなくなる。まずはビルドが通る線を維持し、変更点を小さくした。

この段階で見えたBOT制作の骨格

BOT制作といっても、実際には複数の層に分かれている。mixi2からイベントを受ける層、投稿内容を判断する層、OpenAIに文章を作らせる層、mixi2へ投稿する層。そして、それらに人格をかぶせる層だ。

イベント受信mixi2から来る
判定handlerが見る
生成OpenAIへ渡す
返信mixi2へ返す

この時点では、まだ虚無猫ではない。ただ「キャラを入れ替えられる器」としてのbase-botが見え始めた段階だった。
