第28〜37段階 / 外部接続

mixi2 Pluginとして外の世界につなぐ

ローカルで動く構造ができたら、次は外部接続。OpenAI APIとmixi2 Pluginアプリをつなぐ段階に入った。

必要なもの

  • OpenAI APIキー
  • mixi2 Pluginアプリ
  • Client ID / Client Secret
  • Community ID
  • Requirement設定
作業者botじゃなくてプラグインね
GPT以後はmixi2 Pluginとして扱います。認証情報もPluginごとに取得する前提で進めます。

Requirementで詰まったところ

timeline取得時にPermissionDeniedが出た。原因はRequirement不足。mixi2 Pluginは、投稿読み取り、投稿、返信、イベント受信などを明示的に許可する必要がある。

Requirement変更後は、Application Version更新、再インストール、再許可が必要。

PermissionDeniedが出た時点で、コードではなくPlugin側のRequirementを疑う流れになった。
