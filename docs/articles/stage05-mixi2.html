第28〜37段階 / 外部接続

ローカルのBOTから、mixi2 Pluginへ

ここからは外部サービスとの接続。OpenAI API、mixi2 Pluginアプリ、Requirement、timeline取得、投稿確認へ進んだ。

必要な外部ID

  • OpenAI APIキー
  • mixi2 Client ID
  • mixi2 Client Secret
  • mixi2 Community ID
  • mixi2 Pluginアプリ情報

Requirementでつまづいた点

timeline取得時にPermissionDeniedが出た。原因はPlugin側のRequirement不足だった。mixi2 Pluginでは、投稿読み取り、投稿、返信、必要イベント受信などを明示的に許可する必要がある。

Requirementを変更したら、Application Version更新、再インストール、再許可が必要になる。

この段階の確認

  • OpenAI API接続OK
  • mixi2 Plugin認証OK
  • PluginのコミュニティインストールOK
  • timeline取得OK
  • 投稿確認OK
