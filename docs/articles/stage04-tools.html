第22〜27段階 / 作業支援ツール

作るたびに壊さないための道具を作る

人格や機能を手で切り替えるとミスが増える。なので、PowerShellスクリプトと検証コマンドを足していった。

scripts/ ├─ new-persona.ps1 ├─ switch-bot.ps1 ├─ switch-persona.ps1 ├─ switch-features.ps1 ├─ assetcheck.ps1 └─ test-profiles.ps1

configcheck

cmd/configcheck は、現在の設定が正しく読めているか確認するためのコマンド。

go run ./cmd/configcheck

PERSONA_PATHが存在するか、IMAGE_REF_DIRがあるか、FEATURESが読めているかを見る。これがあるだけで、Railwayに上げる前の不安がかなり減る。

docsフォルダ

docs/ ├─ base-bot-handoff.md ├─ external-id-checklist.md ├─ id-key-acquisition-guide.md ├─ plugin-spec.md └─ stage15-dependencies.txt

ここから、ただBOTを作るだけでなく「後から引き継げる状態にする」方向へ寄っていった。
