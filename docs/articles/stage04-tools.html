第22〜27段階 / 作業支援ツール

毎回手作業で壊さないためのスクリプト

人格や機能を切り替えられるようになると、今度は設定ミスが増える。そこで、PowerShellスクリプトと検証コマンドを整えた。

scriptsフォルダ

scripts/
  new-persona.ps1
  switch-bot.ps1
  switch-persona.ps1
  switch-features.ps1
  assetcheck.ps1
  test-profiles.ps1

new-persona.ps1 は新しい人格フォルダを作る。switch-bot.ps1 は人格と機能プロファイルをまとめて切り替える。assetcheck.ps1 は素材フォルダの存在確認。

cmd/configcheck

設定が正しいか確認するために、cmd/configcheck を追加した。

go run ./cmd/configcheck

これでPERSONA_PATHが存在するか、IMAGE_REF_DIRがあるか、FEATURESが読めているかを確認できる。
