第46段階 / 共有サイト

作業メモを、読める記事にする

最後に、作業メモをGitHub Pagesで公開できる形にした。Plugin本体repoはPrivateなので、公開用に voidcat-plugin-notes を分ける方針にした。

公開用repoの構成

voidcat-plugin-notes/
  README.md
  docs/
    index.html
    timeline.html
    articles/
    assets/
      style.css

ここには作業概要だけを置く。.env、ログ、APIキー、Railway Variables、個人データは置かない。

GitHub Pages設定

Settings
→ Pages
→ Source: Deploy from a branch
→ Branch: main
→ Folder: /docs
→ Save

公開URLは https://megane-hige.github.io/voidcat-plugin-notes/ の形になる。

今後は、BOT制作の記録を人間が読める記事として増やしていく。コマンド集ではなく、設計意図とフォルダ構成が分かる読み物にする。
