第09〜14段階 / 人格と機能切替

人格をコードから切り離す

BOTのキャラクター性がGoコードの中に埋まっていると、別キャラを作るたびにコードを触ることになる。そこで人格を personas に分離した。

personas/ ├─ base/ │ └─ persona.json ├─ fujita/ │ └─ persona.json ├─ kyomu_neko/ │ └─ persona.json └─ suita_coffee/ └─ persona.json

persona.jsonの役割

persona.jsonには、名前、説明、反応ワード、返信の最大文字数、フォールバック文、システムプロンプト、口調、禁止事項を入れる。

つまり、BOT本体は同じでも、ここを変えるとキャラクターが変わる。

PERSONA=kyomu_neko\nPERSONA_PATH=personas/kyomu_neko/persona.json\nFEATURES=reply,theme,scheduled_image,idle_post,image_reply,welcome,admin
作業者人格だけ切り替えられるようにしたい
GPTPERSONAとPERSONA_PATHを使って、読み込むpersona.jsonを変える方式にしましょう。

FEATURESという考え方

人格とは別に、どの機能を動かすかを FEATURES で管理した。返信だけ、歓迎だけ、定時投稿だけ、という使い分けができる。
