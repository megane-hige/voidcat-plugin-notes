第38〜40段階 / 本番デプロイ

GitHubとRailwayで本番へ置く

本番化では、まず秘密値をGitに入れないことを徹底した。Plugin本体repoはPrivateにし、.env、logs、exe、bakは除外した。

.env\n.env.*\n!.env.example\nlogs/\ndata/\n*.exe\n*.bak\n*.log

Railway Variables

APIキーやClient SecretはRailway Variablesに入れる。ローカルの.envはGitに入れない。

Volume化

投稿履歴や返信済みIDなど、消えると困る状態ファイルはRailway Volumeの /data に置いた。

EVENT_LOG_PATH=/data/logs/events.jsonl\nPOST_LOG_PATH=/data/logs/posts.jsonl\nUSER_PREFS_PATH=/data/state/user_prefs.json
git pushGitHubへ反映
