コンフィグの分類

コンフィグは、人格・素材、mixi2接続、OpenAI接続、投稿スケジュール、画像設定、永続化パス、管理者設定、実行環境に分けて考えます。Railway本番ではVariablesとして設定します。

人格・素材

キー例説明確認ポイント
PERSONAkyomu_neko使用する人格キー。専用repoの人格名と一致しているか。
PERSONA_PATHpersonas/kyomu_neko/persona.json人格シートのパス。Test-Path がTrueか。
IMAGE_REF_DIRassets/kyomu_neko/refs画像参照素材のパス。画像機能を使う場合に存在するか。

mixi2接続

キー説明扱い失敗時の症状
MIXI2_CLIENT_IDmixi2 PluginのClient ID。Railway Variables。認証失敗。
MIXI2_CLIENT_SECRETmixi2 PluginのClient Secret。Secret。公開禁止。token取得失敗。
MIXI2_COMMUNITY_ID対象コミュニティID。Pluginごとに違う。投稿先違い。

OpenAI接続

キー説明扱い注意
OPENAI_API_KEYOpenAI APIキー。Secret。公開禁止。空欄上書き事故に注意。
OPENAI_MODELテキスト生成モデル。Railway Variables。コストと品質のバランス。
OPENAI_IMAGE_ENABLED画像生成の有効/無効。Railway Variables。false なら画像機能は実質停止。

投稿・返信

キー説明例
FEATURES有効化する機能一覧。reply,theme,...
SCHEDULED_POST_TIMES定時投稿の時刻。07:15,12:15,19:15
IDLE_POST_TIMES静寂投稿候補時刻。10:30,15:30,21:30
REPLY_IMAGE_PROBABILITY_PERCENT画像返信確率。5

Secret空欄上書き事故

最重要：MIXI2_CLIENT_SECRET="" や OPENAI_API_KEY="" をRailwayに貼ると、実値が空で上書きされます。テンプレや記事では実値を書かず、Railway画面で直接入れる前提にします。
