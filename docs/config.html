configuiとは

cmd/configui は、人格設定をブラウザで編集するためのローカル専用UI。PowerShellで日本語JSONを直接触ると文字化けしやすいため、フォームから編集できるようにした。

起動方法

cd C:\\dev\\mixi2-plugins\\base-bot\ngo run ./cmd/configui\n# ブラウザで http://127.0.0.1:8787 を開く

127.0.0.1 はPC内だけのアドレスなので、スマホからは見ない。スマホから見るのはGitHub Pagesの公開URL。

編集できる主な項目

項目意味
名前 / 呼称名Plugin人格の表示名や呼び方。
反応ワード虚無猫さん、虚無猫、虚無さん、パイセンなど。コミュニティ内の実在呼称と衝突しないように管理。
フォールバック文返信生成に失敗した時などの控え文。
口調短文、静か、ドライ、虚無感などのキャラクター方向。
禁止・回避事項にゃ連発、人格否定、固定語の反復などを避ける。
システムプロンプトOpenAIへ渡す人格の中核設定。

ボタンの意味

ボタン動き注意
保存ローカルのpersona.jsonを保存し、バックアップを作る。本番にはまだ反映されない。
保存してRailway反映persona.jsonを保存、git commit / push、Railway再デプロイへ流す。基本的に人格JSONだけが対象。
バックアップのみ現在のpersona.jsonを退避する。編集前の保険。

FEATURESや投稿時刻などRailway Variablesで管理している項目は、configuiの保存だけでは本番反映されない。ここは今後UI上にも明記する。

公開用の制作記録。APIキー、Client Secret、Railway Variables、.env、ログ、個人データは掲載しない。
