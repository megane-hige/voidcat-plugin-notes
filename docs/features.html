機能ON/OFFの基本

Pluginの機能は FEATURES にカンマ区切りで指定する。全部入りにもできるし、返信だけ、管理者機能だけ、画像なし運用にもできる。

FEATURES="reply,theme,scheduled_image,idle_post,image_reply,welcome,admin"

機能一覧

キー日本語名役割主な場所
reply返信機能投稿やコメントに対してPluginが自動返信する。internal/handler
themeお題生成コミュニティ向けのお題や話題をAIで生成する。internal/handler/theme_entry.go
scheduled_image定時画像投稿定時投稿に合わせて画像付き投稿を行う。internal/scheduler
idle_post静寂投稿一定時間投稿がない場合に、話題提供投稿を行う。internal/scheduler
image_reply画像返信返信時に画像を添付する。internal/handler
welcome新規参加者案内新しく参加したユーザー向けの案内投稿を行う。internal/handler/welcome_entry.go
admin管理者機能管理者向けコマンドや制御機能を有効にする。internal/handler/admin_entry.go

代表的な運用パターン

用途FEATURES例説明
全部入りreply,theme,scheduled_image,idle_post,image_reply,welcome,admin現在の標準形。
画像なしreply,theme,idle_post,welcome,admin画像生成コストや失敗を避けたい時。
返信だけreply,admin最小構成で自動返信を試す時。
管理だけadmin投稿制御や管理者コマンドだけを試す時。

画像機能の注意

FEATURES に画像系機能が入っていても、OPENAI_IMAGE_ENABLED が false なら画像生成本体は止まる。画像を使わない運用ならこのままでよい。画像を使う場合はRailway Variables側で明示的に true にする。
