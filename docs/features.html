Pluginでできること

ここでは、ファイルの場所や内部名ではなく、利用者から見た「できること」だけに絞って整理した。実運用で動く機能に加えて、設定・確認・デプロイ補助まで含めている。

機能名役割
自動返信コミュニティ投稿を見て、虚無猫として自然に返信する中心機能。
反応ワード返信「虚無猫さん」「虚無猫」「虚無さん」「パイセン」などの呼びかけに反応する。
メンションなし返信明示メンションがなくても、条件に合う投稿へ返信できる。
AIお題投稿コミュニティの会話を動かすためのお題や話題をAIで生成する。
定時投稿朝・夕・夜など、決めた時間帯に投稿する運用ができる。
定時画像投稿指定スロットの投稿に画像を添えて投稿できる。
放置時投稿一定時間コミュニティに投稿がない場合、場を動かす投稿を行う。
放置時お題投稿放置投稿時に、通常発言ではなくお題形式の投稿を出せる。
画像返信返信時に一定確率で画像を添える。
画像参照ランダム参照画像フォルダから画像素材をランダム利用できる。
新規加入者歓迎新しく参加したメンバーに向けて歓迎・案内の投稿を行う。
管理者ヘルプ管理者向けの使い方やコマンド案内を返す。
管理者直接投稿管理者コマンドから、Pluginに任意の文章を投稿させる。
呼称設定ユーザーごとの呼び名・表示名の扱いを調整できる。
ユーザー設定保存呼称などのユーザー別設定を状態ファイルとして保持できる。
投稿履歴記録投稿ログをJSONLとして保存し、後から状態確認に使える。
返信済み管理同じ投稿へ重複返信しないように、返信済みIDを記録する。
お題履歴管理過去に出したAIお題を記録し、同じ話題の連発を避ける。
放置投稿履歴管理放置時投稿の履歴を記録し、投稿頻度を管理する。
定時投稿重複防止同じ日・同じ枠の定時投稿を二重作成しないように判定する。
人格切替persona.jsonを差し替えることで、同じ本体を別キャラクターとして運用できる。
機能ON/OFFFEATURES設定により、返信・お題・画像・歓迎・管理機能などを切り替えられる。
OpenAI接続確認OpenAI APIへ接続できるか確認する。
mixi2接続確認mixi2 API、Plugin認証、コミュニティインストール状態を確認する。
timeline取得確認コミュニティ投稿を読み取れるか確認する。
投稿プレビュー実際に投稿する前に、生成される投稿内容を確認する。
投稿確認mixi2へ投稿できるかテストする。
常時ストリーム待機Railway上でイベントを待ち受け、投稿や参加イベントに反応する。
設定確認現在のPERSONA、PERSONA_PATH、IMAGE_REF_DIR、FEATURESの状態を確認する。
ブラウザ設定UIconfiguiで人格設定をブラウザ編集できる。
保存してRailway反映configuiから人格設定を保存し、GitHub push経由でRailway再デプロイへ流せる。
新規人格作成テンプレートから新しいpersonaフォルダを作れる。
人格・機能プロファイル切替PowerShellスクリプトで人格と機能セットをまとめて切り替えられる。
素材チェック参照画像など、人格ごとの素材フォルダが揃っているか確認できる。
複数人格テスト登録済み人格をまとめて切り替え、設定破損がないか確認できる。
Railway Volume保存ログや状態ファイルを/data配下に置き、再起動後も保持できる。
GitHub Pages作業ログPlugin本体とは別に、制作記録を公開サイトとして整理できる。

大きく分けると4系統

会話する自動返信、反応ワード返信、画像返信。
場を動かすAIお題、定時投稿、放置時投稿、歓迎。
人格を変えるpersona.json、人格切替、反応ワード、口調設定。
運用を支えるログ、重複防止、確認コマンド、Railway Volume。

FEATURESで切れる主な実行機能

本番で主にON/OFFするのは次の機能。補助コマンドやログ保存は、運用を支えるための機能として別に存在する。

reply theme scheduled_image idle_post image_reply welcome admin

公開用の制作記録。APIキー、Client Secret、Railway Variables、.env、ログ、個人データは掲載しない。
