Pluginでできること

このページでは、利用者から見た機能と、内部的にどのFEATURESや補助コマンドに関わるかをまとめます。旧版の機能一覧より少なくならないよう、実行機能、補助機能、確認機能、運用機能まで含めています。

機能一覧

機能名役割関連
自動返信コミュニティ投稿を見て、各人格として自然に返信する中心機能。reply
反応ワード返信虚無猫さん、フジタさん、アイちゃんなどの呼びかけに反応する。reply
メンションなし返信明示メンションがなくても条件に合う投稿へ返信できる。reply
文脈参照返信直近投稿や返信ツリーをもとに、単発ではない返答を作る。reply
返信済み管理同じ投稿へ重複返信しないよう返信済みIDを記録する。reply
自己投稿除外BOT自身の投稿に反応し続けないようにする。reply
AIお題投稿コミュニティの会話を動かすためのお題や話題をAIで生成する。theme
お題履歴管理過去に出した話題を記録し、同じお題の連発を避ける。theme
定時投稿朝・昼・夜など、決めた時間帯に投稿する。scheduled_image
定時画像投稿定時投稿に画像を添える。画像生成ON/OFFとは別に制御する。scheduled_image
定時投稿重複防止同じ日・同じ枠の定時投稿を二重作成しない。scheduled_image
放置時投稿一定時間コミュニティに投稿がない場合、場を動かす投稿を行う。idle_post
放置時お題投稿放置投稿時に、通常発言ではなくお題形式を出せる。idle_post
放置投稿履歴管理放置投稿の履歴を記録し、投稿頻度を管理する。idle_post
画像返信返信時に一定確率で画像を添える。image_reply
画像参照ランダム参照画像フォルダから素材をランダム利用する。image_reply
画像スロット指定replyなどの素材スロットを指定する。image_reply
新規加入者歓迎新しく参加したメンバーへ歓迎・案内投稿を行う。welcome
基本ガイド投稿コミュニティの基本ルールや使い方を案内する。welcome/theme
管理者ヘルプ管理者向けの使い方やコマンド案内を返す。admin
管理者直接投稿管理者コマンドからPluginに任意文を投稿させる。admin
返信制御必要に応じて返信挙動を制御する。admin
呼称設定ユーザーごとの呼び名・表示名の扱いを調整する。admin/userprefs
ユーザー設定保存呼称などのユーザー別設定を状態ファイルとして保持する。userprefs
投稿履歴記録投稿ログをJSONLとして保存し、後から確認に使う。logs
イベントログ記録受信イベントをJSONLとして保存する。logs
人格切替persona.jsonを差し替えて別キャラクターで運用する。config
機能ON/OFFFEATURES設定により返信・お題・画像・歓迎・管理機能を切り替える。config
Config UI人格設定をブラウザで編集する。cmd/configui
Config UI一発起動batとショートカットで対象repoのConfig UIを起動する。tooling
新規人格作成テンプレートから新しいpersonaフォルダを作る。scripts
人格・機能プロファイル切替PowerShellスクリプトで人格と機能セットをまとめて切り替える。scripts
素材チェック参照画像など、人格ごとの素材フォルダが揃っているか確認する。scripts
複数人格テスト登録済み人格をまとめて切り替えて設定破損を確認する。scripts
OpenAI接続確認OpenAI APIへ接続できるか確認する。cmd/gptcheck
mixi2接続確認mixi2 API、Plugin認証、Requirementを確認する。cmd/mixi2check
timeline取得確認コミュニティ投稿を読み取れるか確認する。cmd/timelinecheck
投稿プレビュー実際に投稿する前に生成内容を確認する。cmd/postpreview
投稿確認mixi2へ投稿できるかテストする。cmd/postcheck
常時ストリーム待機Railway上でイベントを待ち受け、投稿や参加イベントに反応する。cmd/plugin
Railway Volume保存ログや状態ファイルを/data配下に置き、再起動後も保持する。Railway
GitHub Pages作業ログPlugin本体とは別に制作記録を公開サイトとして整理する。docs

大きく分けると4系統

会話する自動返信、反応ワード返信、文脈参照、画像返信。
場を動かすAIお題、定時投稿、放置時投稿、歓迎。
人格を変えるpersona.json、人格切替、反応ワード、口調設定。
運用を支えるログ、重複防止、確認コマンド、Railway Volume。
