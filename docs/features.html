Plugin機能一覧

このPluginは「全部入り」ではあるが、FEATURES で必要な機能だけをONにできる。コミュニティの運用方針に合わせて、返信だけ、歓迎だけ、定時投稿だけ、という切り方ができる。

機能役割主な場所ON/OFF
reply
通常返信		投稿内容を見て虚無猫が返信する中心機能。internal/handler/reply_entry.goFEATURES=reply
theme
お題投稿		コミュニティ活性化用のお題や話題を出す。internal/handler/theme_entry.goFEATURES=theme
scheduled_image
定時画像投稿		朝・夜など決めた時間に画像付き投稿を行う。internal/scheduler/scheduler_entry.goFEATURES=scheduled_image
idle_post
放置投稿		一定時間投稿がない時に場を動かす投稿を行う。internal/scheduler/scheduler_entry.goFEATURES=idle_post
image_reply
画像返信		返信時に一定確率で画像を添える。internal/handler/reply_image.goFEATURES=image_reply
welcome
歓迎		新加入者向けの基本案内や歓迎投稿。internal/handler/welcome_entry.goFEATURES=welcome
admin
管理者コマンド		管理者用の直接投稿、ヘルプ、呼称設定などの入口。internal/handler/admin_entry.goFEATURES=admin

機能入口の整理

機能ごとの入口を作ったことで、どこを止めれば何が止まるかが見えるようになった。

FEATURESの例

FEATURES=reply,theme,scheduled_image,idle_post,image_reply,welcome,admin

本番ではRailway Variables側で管理する。ローカルの.envをGitに入れないのが重要。

公開用の制作記録。APIキー、Client Secret、Railway Variables、.env、ログ、個人データは掲載しない。
