機能ON/OFFの基本

Pluginの機能は FEATURES で制御します。すべての機能を常に動かすのではなく、コミュニティの性格、BOTの役割、画像生成の有無、運用フェーズに応じてON/OFFできる設計です。

FEATURES="reply,theme,scheduled_image,idle_post,image_reply,welcome,admin"

reply：返信機能

reply は、投稿やコメントに対してPluginが返信する基本機能です。コミュニティ内の会話に参加するBOTらしさの中心になります。ただし、自動返信は誤爆しやすいため、返信対象、返信済みID、BOT自身の投稿、非公開アカウント、管理者コマンドとの衝突などを慎重に見る必要があります。

  • 対象投稿が既に返信済みではないか。
  • BOT自身の投稿に返信しようとしていないか。
  • FEATURESに reply が入っているか。
  • 管理者コマンドやシステム投稿ではないか。
  • 人格のトリガーワードや呼びかけに合っているか。

theme：お題生成

theme は、コミュニティに話題を提供するための機能です。単発のお題、定期的な問いかけ、会話のきっかけ作りに使います。雑談コミュニティでは、BOTが会話の空白を埋める役割を持ちますが、出しすぎるとノイズになります。

  • コミュニティのテーマに合っているか。
  • 前回と似た言い回しになっていないか。
  • ユーザーに答えやすい短さか。
  • センシティブな内容になっていないか。

scheduled_image：定時画像投稿

scheduled_image は、指定時刻に画像付き投稿を行う機能です。朝、昼、夜のあいさつや、キャラクターの存在感を出す投稿に向いています。ただし、画像生成はテキストより失敗要因が多く、コストもかかります。

キー説明
SCHEDULED_POST_TIMES定時投稿の時刻。
SCHEDULED_IMAGE_POST_DELAY_MINUTES画像投稿を何分遅らせるか。
SCHEDULED_POST_HISTORY_PATH定時投稿履歴の保存先。
OPENAI_IMAGE_ENABLED画像生成の有効/無効。

idle_post：静寂投稿

idle_post は、一定時間コミュニティに投稿がない場合に、BOTが話題を提供する機能です。定時投稿と違い、場の静けさを見て投稿するため、コミュニティを自然に活性化しやすい一方で、判定条件を誤ると連投に見える可能性があります。

キー説明
IDLE_POST_ENABLED静寂投稿の有効/無効。
IDLE_POST_TIMES静寂投稿の候補時刻。
IDLE_POST_NO_ACTIVITY_MINUTES何分投稿がなければ静寂とみなすか。
IDLE_POST_COOLDOWN_MINUTES静寂投稿の再投稿間隔。
IDLE_POST_THEME_PROBABILITY_PERCENT静寂投稿でお題化する確率。

image_reply：画像返信

image_reply は、返信時に一定確率で画像を添付する機能です。キャラクター性を出しやすい一方で、毎回画像を出すと重く、コストも高く、会話テンポも崩れやすくなります。そのため、確率制御とスロット指定で軽く扱うのが基本です。

welcome：新規参加者案内

welcome は、新しくコミュニティへ参加したユーザーに案内や歓迎を出す機能です。コミュニティの基本ルール、参加後にしてほしいこと、よくある使い方をやさしく提示できます。

admin：管理者機能

admin は、管理者向けの操作や制御機能です。通常ユーザー向けの返信とは分けて扱います。管理者機能を入れることで、BOTに直接投稿させる、設定状態を確認する、返信制御を行う、といった操作ができます。

機能の組み合わせ例

運用段階FEATURES例狙い
初期接続確認admin管理者操作と起動確認だけを行う。
返信試験reply,admin誤返信しないか確認。
画像なし運用reply,theme,idle_post,welcome,admin画像コストを避けつつ活性化する。
標準運用reply,theme,scheduled_image,idle_post,image_reply,welcome,admin全機能を使う。

ログ・履歴・Volumeとの関係

返信済みIDが消えれば同じ投稿に再返信する可能性があり、静寂投稿履歴が消えれば再デプロイ後に同じような投稿を繰り返す可能性があります。Railwayでは /data Volumeへ保存する構成にします。

REPLIED_LOG_PATH="/data/logs/replied_post_ids.txt"
POST_LOG_PATH="/data/logs/posts.jsonl"
SCHEDULED_POST_HISTORY_PATH="/data/state/scheduled_posts.jsonl"
IDLE_POST_HISTORY_PATH="/data/state/idle_post_history.jsonl"
USER_PREFS_PATH="/data/state/user_prefs.json"
