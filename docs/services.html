BOTを作るのに必要なサービス、アプリ他

ローカル環境、mixi2 Plugin、OpenAI、GitHub、Railwayの準備物

最終更新: 2026-06-16 mixi2 Plugin GitHub Pages

必要なもの一覧

BOTを作るには、コードだけでなく、mixi2 Pluginアプリ、OpenAI API、GitHub、Railway、対象コミュニティが必要になる。

分類必要なもの役割
ローカル環境Windows、PowerShell、Go開発、ビルド、確認コマンド実行。
mixi2Developer PlatformのPluginアプリコミュニティ投稿の読み取り、投稿、返信、イベント受信。
mixi2対象コミュニティPluginをインストールして実際に動かす場所。
OpenAIOpenAI APIキー返信文、お題、画像生成などに使用。
GitHubPrivate repositoryPlugin本体コードの管理。秘密値は入れない。
RailwayService、Variables、Volume常時稼働、環境変数管理、状態ファイル永続化。
公開メモGitHub Pages用repo秘密値を含まない制作記事の公開。

mixi2 Pluginアプリで必要な設定

  • Client ID
  • Client Secret
  • Application Version
  • Requirement設定
  • 対象コミュニティへのインストールまたは再許可

Requirementの注意

mixi2 PluginではRequirement設定が重要。投稿読み取りRequirementが足りないと、timeline取得でPermissionDeniedになる。

PermissionDenied: application does not have permission to read community posts

Requirementを変更した後は、Developer Platform側の設定だけで終わらず、Application Version更新、コミュニティ側の再インストールまたは再許可、mixi2check と timelinecheck の確認まで行う。

Railwayで必要なもの

  • GitHub repo連携
  • Start CommandまたはDockerfile設定
  • Variables
  • /data Volume
  • Deploy successfulの確認
  • ログ上のmissing env、PermissionDenied、panicの確認

公開しないもの

以下は公開記事、GitHub Pages、AIチャット、スクリーンショット、共有資料に含めない。

  • OPENAI_API_KEY
  • mixi2 Client Secret
  • Railway Variablesの実値
  • .env 本体
  • logs、投稿データ、ユーザー情報
  • 実コミュニティ内部の投稿本文
